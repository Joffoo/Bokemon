# Oogiri-Flow

一条顶级大喜利的底层配方是固定的：**7 成常识地基（土台） + 3 成单点错位（ズラし）**。
**俗套不是敌人，俗套的包袱底才是敌人。** 100 个人里 100 个人都能一秒看懂的日常画面，必须保留作为 70% 的稳固地基；只在句末最后 30% 的位置做 **1 处** 彻底背叛预期的跳跃。读者先停顿 0.5 秒（“哈？”），随后 0.5 秒内逻辑接通爆笑（“搞什么鬼！”）。

## Stage 0 地基遥测、平庸三阱与世俗域预筛

1. **提取 70% 常识地基切片（Raw Telemetry）**：剥掉抽象概括与情绪标签，按【图像命题】与【文字命题】分流提取人人秒懂的纯物理底料，记入 `{{raw_telemetry}}`（控制在 100 字以内）：
   - **若为【图像命题】（有画面，缺定性）**：提取画面内真实可见的物理事实——① **力学与微姿态**（视线夹角、重心落点、肢体紧绷处、表情开合度）；② **器物与折旧属性**（材质、磨损、归属或维护代价）；③ **画外与时间轴**（镜头后站着谁？定格前 0.5 秒刚做完什么？定格后 3 秒会发生什么物理后果？）。
   - **若为【文字命题】（如给定场景/主体 X 与特定属性/题眼 Y）**：
     ① **锁定【主体 X 的 5~6 个核心常识地基（土台）】**：必须是 100% 属于该主体最典型、人人都有画面感的原生器物与日常动作（严禁脱离题眼凭空捏造无关的穷酸破败场景）；
     ② **界定【题眼 Y 的单点错位方向（ズラし）】**：用一句纯结构描述，说明如何通过改变“人操作上述原生器物的动作规矩、接触方式或前提认知”来引爆 Y。**【铁律】严禁为题眼 Y 开列外来假道具词表，严禁往主体 X 的原生环境里硬塞不属于它的外来布景，杜绝下游子 Agent 玩“A表词+B表词”的机械拼贴。**

2. **写死平庸三阱（排除俗套オチ与现实观察）**：按大众 1 秒内必踩的三个死穴各写 1 条，共 3 条记入 `{{forbidden_baseline}}`。这 3 条是全场严禁触碰的雷区：
   - **[阱 1 现实观察与字面拆字]**：现实中真会发生的事叫“社会观察”（只会让人叹气觉得真实，不会让人发笑），或把题眼当同音字/多义字做文字拆解游戏。
   - **[阱 2 廉价网梗]**：套用现成网络流行语、谐音梗或放之四海皆准的万能吐槽模板。
   - **[阱 3 情绪直给与自行吐槽]**：直接写出抽象情绪形容词，或在句子里替读者把槽吐了（吐槽是读者的工作，角色自己绝不能觉得好笑）。

3. **物理选矿与装载世俗域**：对照下方 24 类世俗宏观生态域，挑出 **8~10 个其标志性业务动作既能操作【主体 X 原生器物】、又能自然达成【题眼 Y 错位】的世俗域**（保留原序号）记入 `{{secular_domains}}` 下发给 B 轨（仅当命题极度宽泛时才下发全部 24 类）：

```
[1] 市政危房维保   [2] 临期商超早市   [3] 驾校科目考场   [4] 急诊老年康养
[5] 城中村租房中介 [6] 民政婚姻登记   [7] 海关安检清关   [8] 殡葬法事公墓
[9] 县城草台剧组   [10] 典当行拍卖    [11] 餐饮后厨卫生  [12] 业委会物业纠纷
[13] 古董文玩鉴定  [14] 宠物绝育检疫  [15] 长途货运治超  [16] 废品回收拆解
[17] 澡堂足疗技师  [18] 公园象棋摊    [19] 农贸水产批发  [20] 裁缝铺改衣
[21] 修锁配钥匙    [22] 广场舞音响    [23] 老式国营食堂  [24] 高速收费站
```

**完成判据**：`{{raw_telemetry}}` 仅含 100% 纯正的常识地基器物与错位方向，零外来假道具词表；`{{forbidden_baseline}}` 封死现实叹气观察、网梗、情绪三阱；`{{secular_domains}}` 完成 8~10 类预筛。

## Stage 1 三轨并行发散

三轨必须由**三个独立的子 agent 实例**产出，每个实例只看到自己那一轨的提示词。主 agent 在同一会话里替三条轨道各写一份，写出来的是同一个脑子的三种口吻，不是三个极向——那一步等于没做。

按当前 harness 的并行能力派发：

| Harness | 派发方式 |
| --- | --- |
| pi | `subagent`，`agent: "delegate"`（对应 Antigravity 的 `TypeName: "self"`），带三个 task 一次 `workflow: "parallel"`，或连发三次 |
| Antigravity | `invoke_subagent`，`TypeName: "self"`，`Role` 填轨道名 |
| Claude Code / Codex 等带 Task 工具 | `Task`，三个子任务并行 |
| 无子 agent 能力的 harness / 并行受限环境 | 分三个独立回合依序发起，每回合只给该轨提示词（后台静默处理，不向用户输出调试状态） |

具体的 agent 名与参数以当前 harness 实际提供的为准（名字对不上时先 `action: "list"` 查一遍，不要猜）；要守住的是同一件事：每轨一个只看到自己提示词的独立实例。

图像命题若 harness 支持传图，将原图连同 `{{raw_telemetry}}` 一并下发；若不支持传图，以 `{{raw_telemetry}}` 作为唯一视觉基准随提示词下发。

### Subagent A 体面破绽

```markdown
【命题输入】
{{prompt_or_image}}

【常识地基切片】
{{raw_telemetry}}

【先导词】体面破绽
【认知机制】
1. 地基 7 错位 3（1回答1ひねり）：每句只准选用【常识地基切片】中的 **1 个** 原生器物或固有仪式作为 70% 的稳固地基，只在该器物的操作目的或私下规矩上做 **1 处** 错位。严禁同时错位两处以上（错位两处地基即崩塌为怪异病句）。
2. 落差方向与极端反推：地基越庄重/正经，错位越要琐碎世俗；**现实中真会发生的事只是“观察”不是大喜利**，必须往绝对不会发生、但顺着题眼逻辑一秒能接通的极端方向推两步，再往回撤半步。
3. 当事人绝对认真：句中角色绝不是在故意搞笑，他自己无比严肃、真心实意觉得这个荒唐操作是绝妙规矩。

【语言与声学规范】
1. 直接说清铁律（严禁电报哑谜）：每句必须包含 **1 个清晰的具体动词**，一读即懂。省略只用于砍掉解释性废话，绝不为了炫技把句子缩成需要猜谜的名词堆砌。
2. 长度与连贯：不超过 14 字，严禁使用标点符号，严禁在句中使用空格断句。
3. 底词右置（Ochi）：把那唯一的 30% 错位词死死钉在全句最后 2~4 个字，包袱落地立刻闭嘴，严禁在底词后追加半个字的解释。
4. 虚词断头台：严禁出现“的、地、得、了、着、过、其实、原来”等虚词，零情绪形容词。

【负向排除集】以下平庸三阱已被封禁，触碰即作废：
{{forbidden_baseline}}

【交付】输出 3 句一读即懂、地基稳固、末词一击致命的短句。直接输出，每行一句，不加序号。
```

```markdown
{{raw_telemetry}}

【语言与声学规范】
1. 直接说清铁律：必须有 **1 个三岁小孩都能认出的清晰动词**，严禁写成多词硬拼的病句或哑谜，确保 0.5 秒看清单格画面。

3. 底词右置（Ochi）：将暴露异业前提误解的关键动作或口吻钉在句末最后 2~4 个字。
4. 数量：严格按给定清单的序号与类别名逐类输出，每类 1 句。某类无法用单一动作自然咬合时，直接输出该类别名加「无」，严禁硬拼凑数。

【负向排除集】以下平庸三阱已被封禁，触碰即作废：
{{forbidden_baseline}}

【交付】按 `[序号 类别名] 台词` 格式逐行输出（台词内部无空格无标点），序号与类别名必须与给定清单一致。
```

## Stage 2 公诉人证伪裁决与句法骨架重铸

### 第一步：四道客观检视关（任一关不过即出局）

对全部候选逐条过四关：
1. **单点错位与抹除还原关（首要铁律）**：
   - 检查是否符合**“地基 7：错位 3”**：**如果把句末的错位词抹掉、换成普通词，前半句必须能还原成一句 100% 正常、通顺的日常话！**
   - 凡是前半句就已经奇形怪状、把 3 个及以上概念硬捏在一起（“A词+B词+C词”连连看）、往原场景硬塞外来假道具、或删掉动词变成需要猜谜的电报哑谜，第一顺位直接枪毙！
2. **反现实观察与双核替换关**：
   - **淘汰“弱错位（现实观察）”**：现实中真有可能会发生的事（让人读完叹气觉得“确实很惨/很穷/很累”而非荒谬发笑的），一律判死；
   - **破坏性替换测试**：触碰 `{{forbidden_baseline}}` 即死；将原题的【题眼属性】替换成其他无关形容词后句子依然成立的，说明与题眼零耦合，当场判死。
3. **分镜与实词密度关**：画不出包含原题单一道具与清晰人体姿态的单格漫画即死；含 2 个及以上虚词（的/了/着/过/呢/吧）或句中含空格断句的即死。
4. **末词遮蔽关（Ochi 语序验证）**：在前半句为 100% 正常通顺地基的前提下，遮住句末最后 2~4 个字，若前半句已把包袱泄光，当场腰斩或倒装；严禁在底词之后还留有解释性词尾。

**三轨均不设保底**。全灭也照实报，严禁为了让排名好看而复活任何一条。

### 第二步：公诉人式两两死斗（只准证伪，不准吹捧）

通过四关的幸存者进入两两对照：
- **裁决铁律**：比较候选 X 与 Y 时，**严禁写空洞赞美词**。裁判必须扮演公诉人，按 **「落差高度 × 回收利落度」** 质询：哪一条的犯蠢层级更浅（只是工具错而非前提错）？哪一条的画面需要多绕半秒弯子？将较弱者淘汰，最直观、落差最狠的那一条晋级。
- 先在轨内两两PK，挑出 A、B、C 各 1 条**轨道冠军**；三条轨道冠军再两两PK，决出 1 条**总冠军初稿**。

### 第三步：总冠军「句法骨架三向重铸」（修理赘述，拒绝改出哑谜）

拿到**总冠军初稿**后，**严格锁死该初稿的具体原题器物与核心错位事件（严禁偷换道具，且严禁删掉核心动词变成名词堆砌哑谜！）**，按以下 **3 种正交的代数句法槽位公式**尝试重铸（均须 ≤14 字、零标点、零句中空格、底词右置）：

1. **`[现场喝止/当事人独白体]`**
   - **句法公式**：`[70% 正常操作原题器物的前置指令] + [30% 暴露前提误解的突发末词]`
   - **声学特征**：以无比认真的当事人或画外人的口吻直接发话（若原题本身要求“说一句话/台词”，优先取此体）。
2. **`[量化规矩/折算体]`**
   - **句法公式**：`[70% 原题正常器物与动作] + 超/每 [具体刻度] + [30% 荒谬计价或离谱后果]`
   - **声学特征**：将荒诞的前提错位写成场所内一本正经的明文规矩。
3. **`[冷面白描/单动作体]`**
   - **句法公式**：`[70% 场内角色 + 操作原题单一器物] + [30% 错位核心动词与底词]`
   - **声学特征**：极简白描，不加任何修饰词，靠单一动作的反差一击致命。

【**重铸铁律**（ひねりは修理に使う）】：直接说最清楚的梗，就直接说！将【总冠军初稿】与【3 个句法重铸体】同台对决——若某个重铸体为了压字数而损失了“一读秒懂”的通顺度，立即废弃该重铸体；选出最自然、最秒懂、0.5 秒“哈？”之后瞬间爆笑的那 1 句，加冕为最终**全场总冠军**。

**完成判据**：每一条候选都有归属与死因判词；总冠军及有效重铸体均满足“抹掉末词即还原为正常话”，零名词拼贴哑谜。
